# Character images (optional)

Drop transparent cut-out portraits here and the game will use them instead of the built-in vector portraits:

    src/assets/characters/<character id>/<expression>.png      e.g. alex/concerned.png
    src/assets/characters/<character id>/neutral.png           used when an expression is missing

Character ids: alex, daniel, maria, elena (Release Today); player, daniyar, alina, tomas (Speak for Someone Else).
Expressions: neutral, concerned, angry, sad, confident, surprised. png / webp / jpg are supported.
Use only images you have the rights to. If a file is missing the vector portrait is shown, so you can add them one by one.
